## 📌 Project Overview

This repository contains a **Python-based Keylogger** developed as part of a cybersecurity learning project.  
The goal of this project is to understand how keystroke logging works, how input events can be captured, and why such tools pose serious security and privacy risks.

By building this project, students gain hands-on experience with:
- Keyboard event handling
- File logging
- Security awareness and ethical considerations

---

## 🚀 Features

- Captures keyboard input in real time
- Logs keystrokes to a file
- Simple and beginner-friendly implementation
- Easily extendable for learning purposes

## 🧠 How It Works

The keylogger listens for keyboard events and records each keystroke.  
Once the script is running, it captures input until the program is stopped manually.

Captured keystrokes are saved into a log file for later analysis.
